     createSecFetch({ userAgent, fetch = globalThis.fetch, now = Date.now, sleep
     = Bun.sleep }) returns secFetch(url): Promise<unknown> (parsed JSON). It's
     a factory so tests can pass a fake fetch, a fake clock and a fake sleep.
     The fetch param uses a small FetchFn = (url: string, init?: RequestInit) =>
     Promise<Response> type, so plain fakes type-check.

     Inside, in this order:
     1. Cache: Map<url, { data, expiresAt }>. Return it if now() < expiresAt.
        Expired entries are never returned.
     2. Same URL at the same time: Map<url, Promise> of requests in flight. If
        the URL is already there, return that promise. Delete it in finally.
     3. Rate limit: one promise chain plus lastStart. Each request waits on the
        chain, sleeps lastStart + 100 - now() if that's positive, then sets
        lastStart = now(). That keeps at least 100 ms between the starts of two
        requests. A failed request must not break the chain. The chain only
        holds the "wait for my turn" step and never the fetch itself. On top of
        that it's stored as queue = turn.catch(() => {}), so a rejection can
        never reach the next caller. The next request still waits its 100 ms and
        then runs normally.
     4. Fetch with User-Agent and AbortSignal.timeout(10_000). A network error,
        timeout, non-2xx (403/429/5xx) or bad JSON throws
        AppError("UPSTREAM_UNAVAILABLE", …). Failures are not cached.
     5. TTL: 24 h if url === TICKERS_URL, otherwise 10 min.

     index.ts: const userAgent = requireUserAgent(Bun.env) at the top, inside a
     try. On failure it logs and calls process.exit(1). I'm only adding this
     check now. The route chaining and export type App come with the endpoints.

     2. tickers.ts

     resolveTicker(input: string, secFetch: SecFetch): Promise<{ ticker, cik, 
     name }>
     - normalize = (s) => s.trim().toUpperCase().replaceAll(".", "-")
     - Loads TICKERS_URL through secFetch (cached for 24 h). It's an object
       keyed by "0", "1", …, so it uses Object.values(...).find(e => 
       normalize(e.ticker) === normalize(input)).
     - Returns ticker the way the SEC writes it (BRK-B), cik as
       String(cik_str).padStart(10, "0") (your choice), and name = title.
     - Not found: throws AppError("UNKNOWN_TICKER", …). Upstream errors from
       secFetch are passed through unchanged.

     3. filings.ts

     - Submissions: a minimal type with only the fields we read (cik, name,
       filings.recent columns: accessionNumber, filingDate, reportDate,
       acceptanceDateTime, form, primaryDocument, primaryDocDescription, plus
       filings.files for coverage later).
     - FilingRow = Static<typeof Filing> & { acceptanceDateTime: string }. It's
       internal and is used for sorting by date, then acceptanceDateTime, then
       accession number.
     - toFilings(submissions): FilingRow[] is pure. It walks index i across the
       columns and keeps the SEC order. Sorting and filtering happen later in
       the endpoint.
       - reportDate and description (from primaryDocDescription) become null
         when they are "".
       - url = 
         https://www.sec.gov/Archives/edgar/data/${Number(cik)}/${accession 
         without "-"}/${primaryDocument}
     - toFiling(row: FilingRow): Filing builds the response object explicitly,
       field by field, without acceptanceDateTime. Routes call it after sorting
       and paging. We don't rely on Elysia's response normalization to drop
       extra fields.

  - src/sec.ts: createSecFetch({ userAgent, fetch, now, sleep }) returns
    secFetch(url). In order, it:
    - serves fresh cached data (24 h for the ticker list, 10 min for anything
      else);
